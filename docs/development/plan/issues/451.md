## 文档职责

本计划承接 issue #451 的 RFC 目标：为 Agent 开发历史建立 **version-aware** 的 M2 Episode memory——即按 libra 版本（release/commit）记录与回溯 Agent 行为与决策记忆，使记忆具备版本感知、可追溯、可复用。这是记忆/Agent 开发能力的一部分，与 `plan-20260819`（MEM-01/02，R30 重设计）直接相关。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点，再按任务卡验收。

### 适用范围

- M2 Episode memory 的数据模型与版本字段（version / release / commit / 时间线）。
- 记忆写入、读取、按版本回溯的接口；与现有 memory 边界（#500 中央化统计、代理开发历史）的衔接。
- 版本感知的检索/排序策略；仓库内文档与存储格式。

### 非目标

- `plan-20260819` R30 的完整记忆重设计（本计划只做 version-aware 维度的 RFC 落地）。
- 中央化统计数据存储（#500）：本计划只定义 episode memory 的版本感知，不涉及其统计聚合。

### 成功定义

- M2 Episode memory 支持按 libra 版本记录与检索 Agent 开发记忆；不同版本的记忆可区分、可回溯。
- 提供写入/读取/按版本查询的接口与测试；文档同步。
- 与 `plan-20260819` 的 memory 设计无冲突，相关约束登记。
- 任务卡各自可独立验收；完成判据全勾选后才标记完成。
